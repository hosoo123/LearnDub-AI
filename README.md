# LearnDub AI

Сургалтын видео болон хадмалаа нэг дор нээж, англи яриаг Монгол хэлээр ойлгон сурахад зориулсан локал web апп.

## Юу хийж болох вэ?

- MP4/WebM видео болон SRT/VTT хадмал оруулах, эсвэл видеоны англи ярианаас хугацаатай хадмал үүсгэх.
- Хадмалыг ойр орчмын өгүүлбэрийн утга, нэр томьёоны сантай нь хамт Монгол хэл рүү орчуулах. Дууны үгийг тусгай горимоор утга, дүрслэл, давталтыг нь хадгалж орчуулна. Эхэд байгаа хараал, бүдүүлэг үгийн өнгө аясыг хадгална.
- Орчуулгыг засах, эх текст/хугацааг өөрчлөх, мөрөөр видео руу үсрэх, Батаа эсвэл Есүй Монгол neural дуугаар видео дагуулан уншуулах.
- Бүх мөрийг орчуулсны дараа Монгол хадмалтай WebVTT татах.
- Хичээлийг browser-ийн локал санд автоматаар хадгалах, дахин нээх эсвэл устгах.

## Windows дээр эхлүүлэх

Шаардлагатай: Node.js 22.12 ба түүнээс шинэ хувилбар (одоогийн LTS санал болгоно), npm, Ollama. Видео яриа танихад FFmpeg болон FFprobe хэрэгтэй.

```powershell
ollama pull gemma4:e4b
npm ci
if (!(Test-Path .env.local)) { Copy-Item .env.example .env.local }
npm run dev
```

`http://localhost:3000` хаягийг нээнэ. Видео, хадмал оруулаад **Дутуу мөрийг орчуулах** эсвэл **Бүгдийг орчуулах** товч дарна. Орчуулга хийхийн өмнө Ollama нээлттэй, `.env.local` дахь загвар суусан байх шаардлагатай. `.env.local`-ийн тохиргоо өөрчилсний дараа dev серверийг дахин асаана.

### Яриаг хадмал болгох

FFmpeg/FFprobe-ийг PATH-д нэмээд **Видео яриаг таних** товч дарна. Whisper-ийн `onnx-community/whisper-tiny.en` загвар анхны хэрэглээнд Hugging Face-ээс татагдаж `%USERPROFILE%\.cache\learndub-ai\whisper` хавтаст хадгалагдана. Анхны таталтад интернэт хэрэгтэй; дараагийн хэрэглээ локал cache-аас уншина. Танилтад 250 MB хүртэл, 30 минутаас уртгүй MP4/WebM дэмжинэ. FFmpeg өөр замд байвал `.env.local`-д `FFMPEG_PATH`, `FFPROBE_PATH` тохируулна. Whisper дуу, хөгжмийн дээрх үгийг алдаатай таньж болох тул боломжтой бол зөвшөөрөлтэй SRT/VTT үг оруулж, орчуулгын төрлөөс **Дууны үг** сонгон шалгаарай.

### Chrome өргөтгөл

Орчуулга/TTS алдаатай болсон үед popup-д **Алдааг арилгаад дахин оролдох** товч гарна. Сервер/интернэтээ шалгаад уг товчоор Монгол хадмал, дууг унтраалгүй дахин оролдож болно. Ижил контексттэй давхардсан live/prefetch орчуулгын хүсэлтийг нэгтгэнэ. Хуудаснаас гарах үед extension-ийн timer, AI аудио, синк хүлээлтийг цэвэрлэнэ.

**Хүлээлттэй синк горим:** popup-ийн **Дуу бэлдэх зуур видеог хүлээлгэх** сонголтыг асаавал одоогийн мөрийн орчуулга, дуу бэлэн болохыг хамгийн ихдээ 8 секунд хүлээнэ. Унтраалттай үед видео тасралтгүй явна. Өөрөө paused байсан видеог extension автоматаар асаахгүй; seek/play үйлдлээр хүлээлтээс гарч болно. **AI дуу** болон **AI ярианы үеийн эх дуу** гулсагчаар дууны харьцааг тохируулна. Тохиргоо тухайн YouTube табд хүчинтэй; хуудас refresh хийхэд анхны утгадаа орно. Энэ горим нь орчуулгын загварыг хурдан болгохгүй, удаан боловсруулалтын үед видеог түр хүлээлгэж зөрөхийг багасгана.

**Хоцролт ба сул AI дуу:** хугацаатай transcript ашиглаж байвал дараагийн 12 секунд доторх хоёр мөрийн орчуулга, TTS-ийг урьдчилан бэлтгэнэ; TTS урьдчилан бэлтгэх нь зөвхөн Монгол дуу асаалттай үед ажиллана. Pause болон видео buffering үед AI дуу хамт түр зогсож, үргэлжлүүлэхэд тоглож байсан аудионы байрлалаа хадгална. Seek/мөр солиход хуучин аудиог цуцална. Browser-ийн Web Audio боломжтой, audio context нээгдсэн үед AI ярианы RMS түвшнээр 3x хүртэл зөөлөн өсгөж, compressor-оор чанга оргилыг шахна; silence болон эх видеоны хөгжим/шуугианыг өсгөхгүй. Web Audio боломжгүй үед энгийн тоглуулалтад шилжинэ. Энэ нь эх бичлэгийн хүний яриаг хөгжим, шуугианаас салгах систем биш. Зөвхөн харагдах CC ашиглах үед дараагийн мөр мэдэгдэхгүй тул урьдчилан бэлтгэх боломжгүй, серверийн хоцролт хэвээр нөлөөлнө.

**Ярианы өнгө ба хурд:** extension нь эх өгүүлбэр, орчуулгын үг болон цэг тэмдгээс сэтгэл хөдлөлийг таамаглан TTS-ийн хурд, pitch, чангыг өөрчилнө. Уур/догдлолыг илүү эрчтэй, гунигийг удаан унших тохиргоотой. Энэ нь эх аудиог сонсож emotion таних, жүжигчний хоолойг дуурайх боломж биш. Хугацаатай transcript байгаа үед аудионы үлдсэн уртыг cue-ийн үлдсэн хугацаанд харьцуулж, видеоны playback speed-ийг даган 2.5x хүртэл хурдлуулна; хоолойн pitch-ийг playback үед хадгална. Зөвхөн харагдах CC ашиглаж байгаа үед дуусах хугацаа байхгүй тул үгийн тоогоор ойролцоолно. Маш урт орчуулга, удаан серверээс болж мөр тасрах эсвэл уншигдахгүй өнгөрөх боломж хэвээр. Сүүлийн 16 мөрийн аудиог тухайн табын санах ойд хадгалж дахин ашиглана.

Extension-ийн орчуулга өмнөх хоёр хадмалын мөр болон бэлэн орчуулгыг контекст болгон дамжуулна. Хугацаагаар хол үсрэхэд өмнөх ярианы контекст цэвэрлэгдэнэ. Энэ нь залгамж холбоог сайжруулах зорилготой; загварын бодит чанарыг тухайн бичлэг дээр хянах шаардлагатай.

**CC байхгүй бичлэг:** extension цэсний **Бичлэгээс яриа таних** товчоор тусдаа таб нээгээд YouTube дээрхтэй ижил эхлэлтэй, ижил хувилбарын MP4/WebM файлыг сонгоно. Яриа таних горимд том `Whisper base.en` эсвэл жижиг `tiny.en` загвар сонгож болно. Том горимын загварыг `WHISPER_ACCURATE_MODEL` орчны хувьсагчаар, жижиг горимын загварыг `WHISPER_MODEL`-оор өөрчилнө. Анх хэрэглэхэд загвар татагдана. Сервер, FFmpeg/FFprobe шаардлагатай; 250 MB/30 минут хүртэлх англи бичлэг дэмжинэ. Popup хаасан ч ажил үргэлжилнэ; танилтын табыг нээлттэй үлдээнэ. Үр дүнг англи VTT болгон хадгалж болно. YouTube видео солигдсон бол эх видеогоо нээгээд “Видеонд холбох” товчоор дахин холбож болно. Дуусмагц видеоны хугацаанд таарсан танилтын текстийг орчуулна. Хуудас refresh хийхэд энэ түр хадмал арилна. YouTube табын дууг шууд барьж таних боломж хараахан байхгүй.

**YouTube дээр шууд Монгол хадмал:** локал сервер болон Ollama-г ажиллуулаад extension цэснээс **Монгол хадмал асаах** дарна. English CC асаалттай үед харагдаж буй текстийг локал серверт орчуулж, видео дээр харуулна. Fullscreen үед мөн харагдана. Popup хаасан ч ажиллана; дахин нээгээд унтрааж болно. Шинэ мөрийн орчуулга загварын хурдаас шалтгаалан хоцорч болох бөгөөд өөр мөр гарсан бол хуучин орчуулгыг дэлгэцэд тавихгүй. Алдаа гарвал popup-д шалтгааныг харуулна; серверээ шалгаад унтрааж/асааж дахин оролдоно. Монгол хадмал асаасны дараа **Монгол дуу асаах** товчоор Батаа хоолойгоор уншуулна. Орчуулсан текст Microsoft Edge онлайн TTS үйлчилгээнд илгээгдэнэ. Pause/seek, мөр эсвэл видео солиход дуу зогсож, эх дууны түвшин сэргэнэ. Яриа болон орчуулга бэлтгэх саатлаас болж богино мөрүүдийн дуу амжихгүй байж болно.

1. LearnDub AI веб аппыг `http://localhost:3000` дээр ажиллуулна.
2. `npm run build:extension` командыг ажиллуулна.
3. Chrome-д `chrome://extensions` нээгээд **Developer mode → Load unpacked** сонгож репозиторийн `extension` хавтсыг заана. Бэлэн `.zip` багцыг `npm run package:extension` командаар үүсгэнэ.
4. YouTube видеогоо нээж English **CC** хадмалыг асаагаад, LearnDub AI өргөтгөлөөс **Хадмал бичиж эхлэх** дарна.
5. Видео дуусахад **Зогсоож VTT татах** дарж хадмал татна. Веб аппын **Хадмал оруулах** хэсгээр `.en.vtt` файлыг оруулаад Монгол руу орчуулна.

Өргөтгөл нь зөвхөн YouTube дээр хэрэглэгчид дэлгэцэд харагдаж буй CC текстийг бичдэг; CC асааж хадмалыг харуулах шаардлагатай бөгөөд видеоны хадмалын хамгаалалтыг тойрч гарахгүй. Видео солиод бичлэг үргэлжилбэл өргөтгөл үүнийг мэдэгдэж зогсооно. Өөрчлөлт татсаны дараа `chrome://extensions` дээр өргөтгөлийн **Reload** дарна уу.

## Өгөгдөл ба нууцлал

Хичээлийн жагсаалт, видео, хадмал, орчуулга, үзсэн хугацаа нь тухайн browser болон төхөөрөмжийн IndexedDB санд хадгалагдана. LearnDub AI нь аппын сервер рүү автоматаар видео/хичээл синк хийхгүй. Browser-ийн өгөгдлийг цэвэрлэх, өөр төхөөрөмж/профайл ашиглахад энэ локал сан харагдахгүй; хэрэгтэй үр дүнгээ VTT-ээр татаж нөөцөлнө үү. Том видеог хадгалахад төхөөрөмжийн сул зай болон browser-ийн хадгалалтын хязгаар нөлөөлнө.

Local development үед орчуулгын хүсэлт энэ компьютер дээрх Ollama руу явна. Яриа танихад видео өөрийн Next.js аппын серверт (локал ажиллуулсан бол энэ компьютер) дамжиж, Whisper/FFmpeg локал боловсруулна. **Монгол дууг хэрэглэгч өөрөө асаасан үед л орчуулсан текст Microsoft Edge-ийн онлайн TTS үйлчилгээнд илгээгдэнэ**; дууны хурд, өнгийг тохируулахад эх өгүүлбэрийг зөвхөн энэ аппын серверт ашиглана. Монгол дуу ярьж байх зуур видеоных нь эх дуу түр намсаж, хадмалын мөр дуусахад өмнөх түвшиндээ орно. Дуу ашиглахад интернэт хэрэгтэй бөгөөд үйлчилгээний үнэгүй хүртээмж, нөхцөл өөрчлөгдөж болно. Нийтийн production hosting хийхдээ видео боловсруулах нууцлал, хэрэглэгчийн бүртгэл, өгөгдлийн сан, хадгалалтын бодлогыг тусад нь шийдэх шаардлагатай. Энэ хувилбар нь хэрэглэгч хооронд синкгүй локал MVP болохоос олон хэрэглэгчтэй cloud үйлчилгээ биш.

## Загвар ба нэр томьёо

Анхдагч орчуулгын тохиргоо `.env.example`-т байна: `TRANSLATION_PROVIDER=ollama`, `OLLAMA_BASE_URL=http://localhost:11434`, `OLLAMA_MODEL=gemma4:e4b`. Хариу ирэхгүй эсвэл загвар олдохгүй үед апп тохируулсан загвараас эхлэн нөөц загваруудыг ээлжлэн оролддог; тохируулсан загвар эхэлж ажиллахад нөөцүүдэд хүрэхгүй. Орчуулгын төрлийг **Авто**, **Дууны үг**, **Энгийн яриа** гэж сонгож болно. Авто нь файлын нэр, хөгжим/дуулалтын тэмдэглэгээ, дахин давтагдсан мөрөөр таамагладаг; аудиог сонсож дуу мөн эсэхийг баталгаажуулдаггүй тул эргэлзвэл төрлийг гараар сонгоорой. Дууны үгийн горим rhyme-ийг утгаас дээгүүр тавихгүй, Монгол TTS нь дууг аялан дуулахгүй бөгөөд орчуулгыг ярианы хоолойгоор уншина. Орчуулга нь загвараас хамаарч алдаж болох тул экспортлохоосоо өмнө хянаарай. Хэлц, бүдүүлэг хэллэг болон нэр томьёоны заавар `src/lib/translation-glossary.ts` файлд байна. Түгээмэл ярианы хэлцийг контекстоор сонгох, өгүүлбэр хадмалын хэд хэдэн мөр дамнавал орчуулгыг cue бүрт давталтгүй хуваарилах заавар бий.

## Хөгжүүлэлт ба шалгалт

```powershell
npm run dev
npm run check
```

`npm run check` нь web апп болон Chrome өргөтгөлийн lint/typecheck, unit test, production build-ийг ажиллуулна. Өргөтгөлийг тусад нь `npm run build:extension` командаар бүтээж болно.

`npm run typecheck:extension-tests` нь extension-ийн тестүүдийн TypeScript алдааг тусад нь шалгана. `npm run build:extension` дуусахад manifest-ийн popup, background worker, content script, бичлэг таних HTML/JS файлууд бүгд байгаа, хоосон биш эсэхийг автоматаар шалгана. `npm run validate:extension`-ээр үүнийг тусад нь ажиллуулж болно. Build үүсээгүй эсвэл файл дутуу бол ZIP багцлахыг зогсооно. Шалгалт тэнцсэн суулгах ZIP-ийг `npm run package:extension` командаар үүсгэнэ.

## Одоогийн хязгаар

- Өгөгдөл зөвхөн тухайн browser/device дээр байна; нэвтрэлт, cloud backup, олон төхөөрөмжийн синк байхгүй.
- Neural Монгол дуу нь интернеттэй үед үнэгүй ажиллана; Батаа/Есүй дууны өнгө сонгож, эх болон орчуулсан өгүүлбэрийн үг, цэг тэмдгээс хурд, өнгө, чангыг ойролцоогоор тааруулна. Энэ нь тухайн жүжигчний дуу хоолойг дуурайхгүй.
- Whisper tiny.en нь хурдан жижиг англи загвар боловч шуугиан, нэр томьёо, өргөлт дээр алдаж болно. Танилтын үр дүнг шалгана уу.
- Зөвшөөрөлтэй видео болон хадмал ашиглана уу. YouTube-ийн хадмалыг зөвшөөрөлгүй татах/унших үйлдэл энэ апп хийхгүй.
