# LearnDub AI

Сургалтын видео болон хадмалаа нэг дор нээж, англи яриаг Монгол хэлээр ойлгон сурахад зориулсан локал web апп.

## Юу хийж болох вэ?

- MP4/WebM видео болон SRT/VTT хадмал оруулах, эсвэл видеоны англи ярианаас хугацаатай хадмал үүсгэх.
- Хадмалыг ойр орчмын өгүүлбэрийн утга, нэр томьёоны сантай нь хамт Монгол хэл рүү орчуулах. Эхэд байгаа хараал, бүдүүлэг үгийн өнгө аясыг хадгална.
- Орчуулгыг засах, эх текст/хугацааг өөрчлөх, мөрөөр видео руу үсрэх, Батаа эсвэл Есүй Монгол neural дуугаар видео дагуулан уншуулах.
- Бүх мөрийг орчуулсны дараа Монгол хадмалтай WebVTT татах.
- Хичээлийг browser-ийн локал санд автоматаар хадгалах, дахин нээх эсвэл устгах.

## Windows дээр эхлүүлэх

Шаардлагатай: Node.js-ийн одоогийн LTS хувилбар, npm, Ollama. Видео яриа танихад FFmpeg болон FFprobe хэрэгтэй.

```powershell
ollama pull gemma4:e4b
npm ci
if (!(Test-Path .env.local)) { Copy-Item .env.example .env.local }
npm run dev
```

`http://localhost:3000` хаягийг нээнэ. Видео, хадмал оруулаад **Дутуу мөрийг орчуулах** эсвэл **Бүгдийг орчуулах** товч дарна. Орчуулга хийхийн өмнө Ollama нээлттэй, `.env.local` дахь загвар суусан байх шаардлагатай. `.env.local`-ийн тохиргоо өөрчилсний дараа dev серверийг дахин асаана.

### Яриаг хадмал болгох

FFmpeg/FFprobe-ийг PATH-д нэмээд **Видео яриаг таних** товч дарна. Whisper-ийн `onnx-community/whisper-tiny.en` загвар анхны хэрэглээнд Hugging Face-ээс татагдаж `%USERPROFILE%\.cache\learndub-ai\whisper` хавтаст хадгалагдана. Анхны таталтад интернэт хэрэгтэй; дараагийн хэрэглээ локал cache-аас уншина. Танилтад 250 MB хүртэл, 30 минутаас уртгүй MP4/WebM дэмжинэ. FFmpeg өөр замд байвал `.env.local`-д `FFMPEG_PATH`, `FFPROBE_PATH` тохируулна.

### Chrome өргөтгөл

1. LearnDub AI веб аппыг `http://localhost:3000` дээр ажиллуулна.
2. `npm run build:extension` командыг ажиллуулна.
3. Chrome-д `chrome://extensions` нээгээд **Developer mode → Load unpacked** сонгож репозиторийн `extension` хавтсыг заана. Бэлэн `.zip` багцыг `npm run package:extension` командаар үүсгэнэ.
4. YouTube видеогоо нээж English **CC** хадмалыг асаагаад, LearnDub AI өргөтгөлөөс **Хадмал бичиж эхлэх** дарна.
5. Видео дуусахад **Зогсоож VTT татах** дарж хадмал татна. Веб аппын **Хадмал оруулах** хэсгээр `.en.vtt` файлыг оруулаад Монгол руу орчуулна.

Өргөтгөл нь зөвхөн YouTube дээр хэрэглэгчид дэлгэцэд харагдаж буй CC текстийг бичдэг; CC асааж хадмалыг харуулах шаардлагатай бөгөөд видеоны хадмалын хамгаалалтыг тойрч гарахгүй. Видео солиод бичлэг үргэлжилбэл өргөтгөл үүнийг мэдэгдэж зогсооно. Өөрчлөлт татсаны дараа `chrome://extensions` дээр өргөтгөлийн **Reload** дарна уу.

## Өгөгдөл ба нууцлал

Хичээлийн жагсаалт, видео, хадмал, орчуулга, үзсэн хугацаа нь тухайн browser болон төхөөрөмжийн IndexedDB санд хадгалагдана. LearnDub AI нь аппын сервер рүү автоматаар видео/хичээл синк хийхгүй. Browser-ийн өгөгдлийг цэвэрлэх, өөр төхөөрөмж/профайл ашиглахад энэ локал сан харагдахгүй; хэрэгтэй үр дүнгээ VTT-ээр татаж нөөцөлнө үү. Том видеог хадгалахад төхөөрөмжийн сул зай болон browser-ийн хадгалалтын хязгаар нөлөөлнө.

Local development үед орчуулгын хүсэлт энэ компьютер дээрх Ollama руу явна. Яриа танихад видео өөрийн Next.js аппын серверт (локал ажиллуулсан бол энэ компьютер) дамжиж, Whisper/FFmpeg локал боловсруулна. **Монгол дууг хэрэглэгч өөрөө асаасан үед л орчуулсан текст Microsoft Edge-ийн онлайн TTS үйлчилгээнд илгээгдэнэ**; дууны хурд, өнгийг тохируулахад эх өгүүлбэрийг зөвхөн энэ аппын серверт ашиглана. Монгол дуу ярьж байх зуур видеоных нь эх дуу түр намсаж, хадмалын мөр дуусахад өмнөх түвшиндээ орно. Дуу ашиглахад интернэт хэрэгтэй бөгөөд үйлчилгээний үнэгүй хүртээмж, нөхцөл өөрчлөгдөж болно. Нийтийн production hosting хийхдээ видео боловсруулах нууцлал, хэрэглэгчийн бүртгэл, өгөгдлийн сан, хадгалалтын бодлогыг тусад нь шийдэх шаардлагатай. Энэ хувилбар нь хэрэглэгч хооронд синкгүй локал MVP болохоос олон хэрэглэгчтэй cloud үйлчилгээ биш.

## Загвар ба нэр томьёо

Анхдагч орчуулгын тохиргоо `.env.example`-т байна: `TRANSLATION_PROVIDER=ollama`, `OLLAMA_BASE_URL=http://localhost:11434`, `OLLAMA_MODEL=gemma4:e4b`. Хариу ирэхгүй эсвэл загвар олдохгүй үед апп тохируулсан загвараас эхлэн нөөц загваруудыг ээлжлэн оролддог; тохируулсан загвар эхэлж ажиллахад нөөцүүдэд хүрэхгүй. Орчуулга нь загвараас хамаарч алдаж болох тул экспортлохоосоо өмнө хянаарай. Хэлц, бүдүүлэг хэллэг болон нэр томьёоны заавар `src/lib/translation-glossary.ts` файлд байна.

## Хөгжүүлэлт ба шалгалт

```powershell
npm run dev
npm run check
```

`npm run check` нь web апп болон Chrome өргөтгөлийн lint/typecheck, unit test, production build-ийг ажиллуулна. Өргөтгөлийг тусад нь `npm run build:extension` командаар бүтээж болно.

## Одоогийн хязгаар

- Өгөгдөл зөвхөн тухайн browser/device дээр байна; нэвтрэлт, cloud backup, олон төхөөрөмжийн синк байхгүй.
- Neural Монгол дуу нь интернеттэй үед үнэгүй ажиллана; Батаа/Есүй дууны өнгө сонгож, хадмалын үг ба цэг тэмдгээс сэтгэл хөдлөлийг ойролцоогоор тааруулна. Энэ нь тухайн жүжигчний дуу хоолойг дуурайхгүй.
- Whisper tiny.en нь хурдан жижиг англи загвар боловч шуугиан, нэр томьёо, өргөлт дээр алдаж болно. Танилтын үр дүнг шалгана уу.
- Зөвшөөрөлтэй видео болон хадмал ашиглана уу. YouTube-ийн хадмалыг зөвшөөрөлгүй татах/унших үйлдэл энэ апп хийхгүй.
